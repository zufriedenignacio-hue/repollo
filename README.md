# repollo

## Skills

- **relevo**: trabajo en cadena con agentes. Uno produce, otro revisa el output del anterior y se corrige lo bloqueante, con un tope de dos rondas y un esfuerzo calibrado a la tarea.
  - Está en `.claude/skills/relevo/`, así que se activa sola en cualquier sesión sobre este repo.
  - Para usarla en cualquier proyecto, copia la carpeta a `~/.claude/skills/relevo/` o instala el `.skill` en tu perfil.
